\section{Implementation-Exact TSD}

\subsection{Same-State Conditional Contrast}

At reverse step $t$, both frozen branches receive the same latent $z_t$,
timestep, text metadata, and image-token geometry. The target branch additionally
receives the reference image, while the base branch receives the style text
without reference-image evidence. Their velocity contrast is
\begin{equation}
g_t = v_\theta(z_t,t,c_{\mathrm{ref}})-v_\theta(z_t,t,c_{\mathrm{text}}).
\label{eq:supp-contrast}
\end{equation}
Because the velocity-to-score map is affine at fixed $z_t$ and $t$, this
contrast is proportional to a conditional score difference. Both branches use
the same frozen network; no adapter or fake-score model is required by TSD.

\subsection{Detached Pseudo-Target and Reverse Step}

Let $\hat x_0=z_t-\sigma_t v_\theta(z_t,t,c_{\mathrm{text}})$ be the current
denoised estimate. TSD forms
\begin{align}
\widehat g_t &= \frac{g_t}{\sqrt{\operatorname{mean}(g_t^2)+\epsilon}},\\
x_0^{\mathrm{tgt}} &= \sg\!\left(\hat x_0+\eta\widehat g_t\right),\\
\mathcal L_t &= \tfrac12\lVert \hat x_0-x_0^{\mathrm{tgt}}\rVert_2^2.
\end{align}
The teacher contrast and pseudo-target are detached; gradients flow only
through the base clean-state prediction to the current latent. After the inner
latent updates, the unmodified frozen scheduler advances to $z_{t-1}$. This
alternation is the operational meaning of reverse-process regularization: a
bounded task update is repeatedly followed by the model's native inference
dynamics. It is an empirical design, not a theorem of exact projection or
distribution matching.

\subsection{Algorithm}

The inference loop is given as Algorithm~1 in the main paper; we do not repeat it
here. Two implementation-exact points matter for replication. First, the task
target is a \emph{detached} $x_0$ pseudo-target at distance $\eta$ from the
current denoised estimate --- not a raw velocity gradient --- and the conditional
contrast (Eq.~\ref{eq:supp-contrast}) is rms-normalized, which makes any positive
scalar multiplying $g_t$ algebraically inert. Second, the effective controls are
therefore only the reverse-step count, the inner-iteration count, the pseudo-step
size $\eta$, and the normalization granularity.

\section{Evaluation Protocol}

\paragraph{Benchmark.}
The main benchmark contains 40 reference styles and one fixed content prompt,
``a panda eating bamboo,'' using seed 65. Thus the current error summaries
measure cross-style dispersion, not random-seed uncertainty. A paired
three-seed extension over seeds 64--66 is specified in the released benchmark
protocol and remains pending GPU availability. The prompt extension uses five
media-diverse styles and four additional prompts: a seaside castle, a cat on a
windowsill, a sunflower field, and an aged fisherman.

\paragraph{Metrics.}
CSD cosine similarity measures reference-style fidelity. CLIP-T measures
alignment to the literal content prompt rather than the expanded style prompt.
Layout leak is the correlation between off-diagonal patch self-similarity
structures of the reference and output; higher values indicate greater
composition transfer. These axes are interpreted jointly because high CSD can
coincide with subject collapse at extreme settings.

\paragraph{Baseline.}
The native baseline uses the same frozen checkpoint's image+text editing path.
Its style instruction is folded into the user prompt because the public
checkpoint exposes no separate system-prompt channel. We evaluate both a
composition-preserving instruction and a new-composition instruction.

\paragraph{Blinded paired protocol.}
Each evaluation request contains one style reference and two anonymous
candidates for the same task and content prompt. Candidate A/B order is
deterministically randomized by task, style, and judge model. The primary judge
scores all 40 Semantic pairs and all 40 Global pairs. It assigns integer 1--5
scores to medium/technique, texture/mark-making, palette/tone, subject fidelity,
task locality, and visual quality, then records a tie-aware pairwise preference
and concise visual evidence. Task locality is deliberately mode-specific:
reference-composition preservation for Semantic Style Editing, and composition
independence for Global Style Transfer.

\paragraph{Aggregation and audit.}
The radar plot uses the complete primary judge, reporting means over 40 styles
and 95\% percentile bootstrap intervals from 10,000 style-level resamples
(fixed seed 20260723). A secondary VLM independently evaluates 68/80 paired
cells. Twelve cells repeatedly return empty or malformed API payloads; we report
that coverage and perform no imputation. The secondary model is used only for
agreement auditing, not to alter the full primary means. All prompts, order
mappings, raw responses, failures, normalized scores, and aggregation scripts
are included with the figure package.

\paragraph{Results and reliability.}
The primary Agent prefers TSD in 39/40 Semantic pairs and 37/40 Global pairs.
Across the three style axes, TSD gains 2.5--2.9 points over the matched native
edit. Subject fidelity decreases by approximately 0.6 points in both modes.
Semantic locality improves by 3.45 points, whereas Global composition
independence decreases by 1.63 points; this is the perceptual counterpart of
the measured layout-leak trade-off. Beyond the preferred-method agreement noted
in the main paper, the two Agents' per-axis Pearson correlations are 0.957
(medium), 0.960 (texture), 0.977 (palette), and 0.925 (task locality). The
visual-quality score is less rank-stable ($r=0.431$), although 99.3\% of paired
ratings remain within one point.

\paragraph{Validity boundary.}
The primary and secondary task evaluators are both Gemini-family models. The
separate local Gemma-4-family experiment below validates reference-specific
style discrimination with a wrong-reference control, but evaluates only the
style dimension rather than the full six-axis rubric. Thus this protocol is a
reproducible Agent-based perceptual benchmark and diagnostic, not a replacement
for human evaluation.

\subsection{Targeted Public-Editor Audit}

\paragraph{Protocol.}
We additionally compare against the public Qwen-Image-Edit-2511 and
FireRed-Image-Edit-1.1 checkpoints. This audit reuses the five style IDs fixed
beforehand by the qualitative figure (00, 09, 10, 23, and 34); no result-based
style selection is performed. Beyond the matched inputs stated with the
main-paper audit table, each public editor is run at 40 inference steps and true
CFG 4.0. For every task--style
cell, the Agent sees the reference followed by four anonymous, deterministically
randomized candidates: TSD, native MMDiT, FireRed, and Qwen. It scores the same
six axes jointly. Because the public systems use different backbones and were
trained for general editing, this is a matched-input perceptual stress test,
not a compute- or architecture-matched leaderboard.

The primary-Agent means for this audit are reported as the public-editor audit
table in the main paper and are not repeated here; below we give the extended
per-axis cross-Agent analysis that the main paper omits for space.

\paragraph{Results and boundary.}
For Semantic editing, TSD averages 4.60 over medium, texture, and palette,
versus 4.00 for Qwen, 3.60 for FireRed, and 2.53 for native MMDiT; its
composition-preservation score is 5.00, while its subject-fidelity score is
lower (3.80 versus 5.00 for all three alternatives). For Global transfer, TSD
scores 4.87 on the three style axes, versus 4.13, 2.27, and 2.47, respectively.
The native edit remains best at composition independence (5.00); TSD reaches
3.40, FireRed 3.00, and Qwen 2.00. The primary Agent selects TSD as the best
style candidate in 3/5 Semantic and 5/5 Global cells. A complete Gemini-3.5
Flash audit agrees on the best-style candidate in 80\% of cells for each task.
Across 40 candidate-level ratings per axis, cross-Agent Pearson correlations
are 0.89 for medium, 0.90 for texture, 0.77 for palette, 0.90 for subject, and
0.64 for locality. Visual-quality ranking is unstable ($r=0.15$), although all
ratings differ by at most one point; we therefore make no external-model claim
based on that axis.

The main paper summarizes the third-judge wrong-reference control; here we give

\section{Why We Omit a Learned Fake Score}

\subsection{The Frozen Reverse Step Is the Shield}
As introduced in the main text, we scale the frozen scheduler displacement
$z\leftarrow z+\rho\,(\mathrm{step}(z)-z)$ by $\rho\in\{1,0.5,0\}$ at a fixed
task update. Figure~\ref{fig:supp-reverseshield} shows the full grid over all
five fixed styles. At $\rho=0$ the model is still evaluated (the scheduler call
is retained for matched forward-pass accounting) but its displacement is
withheld, so only the fixed-magnitude task updates move the latent; every medium
--- pop-art, bronze relief, oil, mosaic, and stained glass --- then drifts
off-distribution into the same structureless noise, while $\rho=1$ recovers a
clean stylization and $\rho=0.5$ interpolates. Because this is not merely
disabling the sampler (the task optimization is unchanged and the model is still
evaluated), the style-independent collapse isolates the reverse process as the
necessary inference-time regularizer, which together with the fake-score
ablation is why an auxiliary learned network is unnecessary in the evaluated
single-sample regime.

\paragraph{Scale invariance.}
Before normalization, the conditional contrast contains the factor
$(\alpha-1)$. After rms normalization, every positive scalar factor cancels.
Accordingly, guidance scales 4, 7, 10, 15, and 20 produce near-identical
updates and no scale-induced collapse. This result should be interpreted as an
implementation property, not as evidence that arbitrary changes to direction,
step size, or normalization are harmless.

\paragraph{Structured VLM diagnostic.}
On hard styles 04, 14, and 16, a structured VLM judge changes style capture
from partial under score matching to full under TSD, while retaining full
content preservation; fidelity rises from 2--4 to 4--5 on a five-point scale.
Style 21 is unchanged at fidelity 4 and remains limited primarily by color.
This diagnostic is supportive rather than a substitute for human evaluation.

\section{Rejected Generator-Native Metric}

We tested Score-Residual Style Distance (SRSD), the rms magnitude of the same
reference-conditioned velocity contrast evaluated on a completed output. If it
were a style distance, lower residuals should correspond to higher CSD. The
observed relation is the opposite: across $n=\SRSDN$ outputs, Pearson
$r=+\SRSDPearson$ and Spearman $\rho=+\SRSDSpearman$. The correlation is
dominated by over-stylized samples that copy reference composition and lose
subject identity. Within a fixed configuration, the correlation falls to
$r=0.20$ and is not significant; schedule-scale corrections do not change the
conclusion. We therefore reject SRSD rather than invert it, because inversion
would reward the same content-collapse pathology.

\section{Limitations and Remaining Validation}

TSD is optimization-based at inference. The full 40-style benchmark isolates
its gain over the same checkpoint's native edit; the public-editor comparison
is limited to a fixed five-style audit and is not a compute-matched leaderboard.
Exact motifs remain out of scope. The regularization substitution is empirical
and is directly probed by the reverse-step ablation
(Figure~\ref{fig:supp-reverseshield}); it is a qualitative knock-out, and paired
multi-seed uncertainty is queued under the released protocol but remains outside
the current evaluation budget. Human preference is deliberately excluded from
the present validation scope.
